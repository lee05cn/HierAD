项目优势

六件让它区别于「逐帧看图说话」的事。

01

只在间隙里说话

解说窗口由 Whisper 的对白时间轴反推，再用静音检测二次确认；每句话的字数由它所在间隙的长度决定，合成后不越界、不盖台词。

02

层次化理解

不是逐帧看图说话：VLM 先逐场景密集描述，LLM 再汇总场景摘要、人物关系与事件链，最后结合全局剧情把每段压成一句解说。

03

人物称呼一致

可接入 TMDB 演员库与人脸向量库（InsightFace + Faiss），让同一个角色在全片里始终用同一个称呼，不会一人多名。

04

产出直接可用

输出带解说的成片：解说音轨混入原声、字幕烧进画面，另附 SRT 字幕文件，总时长与原片对齐。

05

断点续跑

每个阶段都落盘检查点，中断后重跑会复用已完成的部分，不重复消耗 VLM 与 LLM 的调用额度。

06

模型可替换

VLM / LLM / ASR / TTS 四个环节都是独立 provider，云端 API 或自建服务都行，换模型不用动流程代码。

解说怎么挤进去

难点不是描述，是时机——话必须落在没人说话的那几秒里。

01

切出间隙

Whisper 识别对白时间轴，再从语声里挖掉真实静音，剩下的空档才是解说能落脚的地方。

02

读懂画面

VLM 逐场景读画面，LLM 串起人物与剧情走向，再把这一段的重点压成一句话。

03

按长度配音

每句话的字数由它所在间隙的长度决定，CosyVoice 合成后与画面时长对齐，不越界。
